Engineering Highlights & Design Decisions

            
    
              
  • 
                Messy Data Normalization:
    
                Built an automated data-cleaning pipeline to process 2,049 rows of raw CRM exports, including handling missing or inconsistent names, normalizing phone numbers into standardized digit-based keys, mapping different status values into 7 canonical states, and parsing various date formats.
              
    • 
              
  • 
                Scalable Two-Stage AI Deduplication:
    
                Designed an efficient deduplication process using Inverted Index Blocking instead of brute-force pairwise comparison. This reduces the computational complexity from O(N²) to approximately O(N), allowing around 2,000 records to be scanned in under 0.5 seconds.
              
    • 
              
  • 
                AI-Based Source Extraction (NLP):
    
                Developed an NLP pipeline to extract structured marketing channels and source details from unstructured sales notes. The system uses LLaMA 3.3 70B via OpenRouter, with a local regex-based rule engine as a fallback to maintain reliability when the AI service is unavailable.
              
    • 
              
  • 
                Production-Ready REST API & Dynamic Export:
    
                Implemented a complete REST API with GET, PATCH, and POST /ingest endpoints, along with dynamic CSV exports based on user-defined filters. The API also includes automatically generated OpenAPI/Swagger documentation for easier integration and testing.
